# Industrial Equipment Monitoring Platform Assessment

## Overview

This repository contains my technical assessment submission for the Data Scientist / AI-ML Founding Employee role at Aurik Technologies.

The solution demonstrates the design of a scalable machine health monitoring platform that integrates data from multiple industrial equipment vendors, normalizes heterogeneous datasets, generates explainable machine-level scores, and exposes backend-facing APIs.

---

## Assessment Deliverables

- Vendor Data Assessment
- Data Validation & Normalization
- Unified Machine Data Model
- Machine Health Score Design
- Confidence / Reliability Score
- Maturity / Readiness Score
- Feature Engineering & Future ML Strategy
- Backend API Design
- High-Level System Architecture
